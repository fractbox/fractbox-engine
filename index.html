No GPU — rendering in ASCII

Neither WebGPU nor WebGL2 is available here, so you're seeing the engine's CPU backend: the same distance-estimated formulas, traced into colored text (core/cpu.js). On a WebGPU-capable browser (recent Chrome or Edge) this page renders on the GPU instead.
